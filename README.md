# Grass Touchers

The Grass Touchers fantasy football league site as an Android app.

**Download:** get the latest `.apk` from [Releases](https://github.com/GetHorizontal63/gridiron_android/releases),
open it on your phone, and allow installs from your browser if Android asks. Updates install over the old version.

League scores, rosters and stats load live from the league site, so the app stays current without updating.
